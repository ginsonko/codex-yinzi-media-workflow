# 精确作曲路线：组件许可（2026-11 整理，发布前以各包内的使用须知为准）

`python scripts/score_setup.py --licenses` 打印同一张表。用户要商用、上架、投稿时，交付前必须把「不可商用 / 未写明」这几行原样告诉用户。

| 组件 | 用途 | 能否商用 | 要点 |
|---|---|---|---|
| 绮萱 Qixuan v2.7.0 | 甜美少女主唱 | 可以 | 注明声库「绮萱」、技术「DiffSinger」，明显位置标 AI 合成；禁止拿输出训练模型、禁止改权重；二次分发须完整免费 |
| Alemon 柠檬君 v3.5 | 浑厚男声、说唱、群喊 | **未写明 → 按不可商用** | 仓库没写使用规约；商用前联系作者 |
| Ria 狸安 v0.4 | 中性偏男、粤语 | **未写明 → 按不可商用** | 白名单制：只写了可作为媒体传播并注明声库名；禁止 RVC/SVC 变声处理 |
| DiffSinger 社区声码器 PC-NSF-HiFiGAN 2025.02 / NSF-HiFiGAN 2024.02 | 所有 DiffSinger 声库发声都要它 | **不可（CC BY-NC-SA 4.0）** | 权重非商业许可；成品商用前要向 OpenVPI 确认或换可商用的声码器。这一条决定了目前整条路线默认只适合个人、内部和非商业作品 |
| warble | 歌声合成命令行 + 审听 | 可以（MIT） | |
| FluidSynth | 伴奏渲染 | 可以（LGPL-2.1，只调用可执行文件） | |
| GeneralUser GS | 默认音源 | 可以 | 作者允许私人和商业音乐制作 |
| MuseScore_General | 可选音源 | 可以（MIT） | 保留版权声明 |
| faster-whisper large-v3-turbo | 审听核对字音 | 可以（MIT） | 只用于检查，不进成品 |

大文件都不进安装包，第一次用时下载到数据目录（默认 `<工作流数据目录>/score-music`，可用 `--root` 或 `OMNI_SCORE_MUSIC_ROOT` 换盘）。声库不得随软件或作品二次分发。
