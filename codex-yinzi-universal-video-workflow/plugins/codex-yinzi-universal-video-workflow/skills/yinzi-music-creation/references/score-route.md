# 精确作曲路线（写谱 → DiffSinger 唱 → 伴奏 → 混音 → 审听）

像人一样作曲：你（大模型）写词、旋律、和声、节奏，每个字唱哪个音、唱多长都写进谱；DiffSinger 声库照谱逐字唱，伴奏从和弦表渲染，混音母带到 -14 LUFS，最后用语音识别和节拍检测自己听一遍。全程本机、不花钱。

## 什么时候选它，什么时候选 AI 整首生成

| 选精确作曲 | 选 AI 整首（YuE2 / 在线歌曲服务） |
|---|---|
| 歌词一个字不能错、梗要落在指定拍上（自夸曲、相声说唱、广告歌、课堂儿歌） | 只给一句心情或故事，要「听起来像一首完整的歌」 |
| 要两三个角色对唱、应援接梗、捧哏卡在拍缝里 | 单人演唱、风格优先、细节无所谓 |
| 要给 MV 卡点：每句起止秒数、LRC、节拍样片都要精确 | 要真人感的混响、乐队质感、炸耳的编曲 |
| 要改一句只重唱一句（工程可改，旧版不覆盖） | 不满意就整首重抽 |
| 要零费用 | 可以花钱或有合适的本地显卡 |

两条路可以组合：AI 整首出灵感 → 扒成 MIDI → 进本路线精修；或本路线出精确人声，伴奏换成 AI 生成的纯音乐。

## 实测水平（2026-11 两道考题）

- 偶像流行（156 BPM，6 轨 DiffSinger：主唱绮萱 + 和声 + 4 轨保镖群喊）：主人听后评价「确实好听」；母带 -14.0 LUFS、零削波；人声轨拼音召回 90.8% → 加咬字处理后 93.5%，整混音 85.8%。还差的地方是快字声母和伴奏掩蔽，95% 是下一步目标。
- 相声说唱（104 BPM）：声调滑音写法的 DiffSinger 说唱 + 真唱副歌。配音（TTS）念出来是「在念旁白，不是在唱」——**配音不能当歌声用**，只能用于不卡拍的念白（报幕、「去你的吧」），或在「配音逐字卡拍」对比实验里先逐字对齐再逐字变速卡进拍点；没卡拍的配音一律标「占位」，不进成品。

## 讲故事的歌：故事用说，唱留给高潮（主人实测结论）

相声、故事说唱这类歌，主人听了三版：全程 DiffSinger 说唱（「不太行」）、说唱和唱混着来（「捧哏用唱的一点都不好听」）、故事全用说只留一段唱（采用）。做法：
- 故事、捧哏接话全用配音库念白，自然语速，不卡拍；下面垫低音量律动，包袱落地处加惊堂木，反转处乐队骤停。
- 只留一段完整的唱给升华：乐队全停，一句真心话，接无伴奏多声部清唱，再升调加重低音轰砸进全编制副歌。
- 配音库选声：逗哏用 MiniMax「搞笑大爷」（北方口音），捧哏用「不羁青年」，两个男声反差够、像相声。「搞笑大爷」音量偏大，要把 vol 调到 0.6 左右，不然会削波。
- 念白不卡拍，这是有意的：只有唱段要卡在节拍网格上。歌词字幕版要按标点切句，念白一行不超过 15 个字。

## 步骤

1. **准备**（第一次）：`python scripts/score_setup.py --inspect` 看数据目录和磁盘；告诉用户要下载多大、哪些声库不可商用，再 `--prepare --components warble,fluidsynth,sf-generaluser,vocoder-pc-2025,qixuan[,alemon,ria,whisper] --root <空间够的盘>`。已经下过的文件夹用 `--adopt id=路径` 登记，不重复下。之后的命令都用 `<root>/venv` 里的 python。
2. **写谱**：按 `scripts/score_song.py` 头部注释写 `song.json`（例子 `scripts/examples/mini_song.json`）。规则：
   - 先定 BPM、调、段落表（每段写梗），再写每个字的 `[小节, 拍, 拍数, 字, 音高, 标签]`。快歌每 4 小节至少一个梗点。
   - 主唱旋律放在声库舒服的音域（绮萱 E4–D5；Alemon E2–A3）。应援、捧哏放在主唱的休止里，绝不和主唱叠字。
   - 说唱写成 `rap` 标签的音符：音高给一个窄区中心（男声 E3–A3），脚本按字的声调自动画滑音，重拍加重；捧哏接话用 `pocket`。
   - 多音字写第七项拼音（如 `["行","...","hang"]`）。
   - 和弦表 `[小节, 拍, 拍数, 名字, 低音 MIDI, [和弦音 MIDI]]`，风格 `pop / boombap / ballad`。
3. **样片先行**：`score_song.py song.json --out <工作文件夹>/音乐/<歌名> --demo`（钢琴+鼓），看报告里的拼音召回、节拍锁定分，人耳听结构和梗。改谱再出，旧版自动保留为 `_v2`、`_v3`。
4. **正式版**：去掉 `--demo`。只改了伴奏或混音时，已有的人声分轨直接复用（`--force-vocals` 才重唱）。
5. **字幕版 / MV 节拍样片**：`python scripts/lyric_video.py <母带.wav> <工程/lyric_lines.json> <输出.mp4>`——主唱粉色在上、其余角色蓝色在下，逐字高亮，带小节拍号节拍灯，¥0。要拍 MV 时交给超级导演当节拍样片（付费生成先等用户点头）。
6. **审听**：报告 `qa` 一节 + `scripts/score_qa.py` 可单独复查。看 `listening_notes`；数字只是提示，最后一定要人耳听情绪和咬字。

## 咬字和混音（实测有效的做法）

- 快字（≤半拍）`cons=1.22`、`vel=96`：声母更长、不吞字；零声母字（安、一、眼）前面留 15 tick 微气口防连读。
- 主唱 2.6 kHz +3 dB、3.9 kHz +3.5 dB，350 Hz −3.5 dB；压缩器 attack 8 ms 让字头冒出来；混响前加 40 ms 预延迟。
- 伴奏 350 Hz −5 dB、620 Hz −3.4 dB、2.8 kHz −2.6 dB 给人声让位，有人唱时 1–4.4 kHz 再动态压 4–5 dB；`band_gain` 默认 0.5。
- 群喊：一轨居中保留清晰字头，其余叠唱轨低通 4.2 kHz、错位 ±4.5 ms，只加厚度不加字，否则字头打架听不清。
- 母带 -14 LUFS、真峰 -1 dBFS、零削波。

## 交付与口径

- 每个出声的文件写清：哪个引擎（DiffSinger / 配音）、唱 / 说唱 / 念白、是否占位。
- 交付：母带 WAV+MP3、样片、LRC、字幕版 MP4、歌词梗标注、`.ustx`（OpenUtau 可打开）、人声 / 伴奏 MIDI、分轨、审听报告。
