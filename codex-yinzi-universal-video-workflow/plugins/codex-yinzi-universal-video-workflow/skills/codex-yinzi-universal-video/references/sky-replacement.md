# 图片和连续视频换天

适用于已拍照片、旅行片段、建筑外景的天空替换。先看原画面的光线、镜头移动和遮挡，再选色温、太阳方向与地平线合适的天空素材。`local.image.sky-replace` 和 `local.video.sky-replace` 使用本地 `vision.sky-seg` 组件；首次调用按固定版本下载并验证 ONNX，之后本机 CPU 推理。组件目录可复用，模型缺失时由现有组件管理器准备。

用 `sources` 登记替换天空，`sky_source` 是该数组中的数字索引。`route: auto` 默认自动分割；已有精细蒙版时使用 `route: user_mask` 并设置 `mask_source`。白色替换天空、黑色保留前景。静态用户蒙版适合固定镜头；运动镜头需要逐帧对齐，不能用第一帧蒙版一路遮盖。

天空比例很低时操作返回 `unchanged`，原画面保留；这不代表分割程序崩溃。不要为得到“有变化”盲目降低 `min_sky_coverage`。整幅天空或全白用户蒙版可以是有效输入。

验收时对照原图检查屋顶、烟囱、树叶、电线、地平线；视频还要看遮挡、轮廓拖影与镜头切换。`horizon_blend_px` 默认 0；增大它会把天空混入前景，只在地平线确实需要柔化时使用。羽化控制柔和程度，不能修正错位。自动分割输出的 `quality_status: review_required` 需要真实看图后补效果结论。

实际修复经验：模型把原图拉伸到方形后，蒙版须按相同归一化坐标还原至原始宽高；恢复时使用裁切式 cover 会让横图/竖图轮廓错位。不要把这种几何错误误判为模型不够大。CPU连续处理应复用同一推理会话并在结束/失败时释放，视频用流式解码与编码避免缓存整片PNG。

`refine_edges` 在自动分割时默认开启，使用当前画面颜色细化轮廓；`edge_options` 可调局部范围、羽化和时域混合。镜头运动时以当前帧为准，画面或蒙版显著变化处减少上一帧混合，避免旧轮廓拖影。用户蒙版默认保留原边界，需要时显式开启细化。额外 `feather_px` 默认 0；先修正几何和边缘，再按画面需求增加柔化。

当前实拍平移样本已验证 9.5 秒/114 帧、起音偏差约 0.33 毫秒、无天空图片像素保持；屋顶和烟囱轮廓明显改善，细树叶、电线仍可能残留冷边。精细广告、头发级抠像、复杂反射匹配需结合当前素材选择精修蒙版/AE合成等后续步骤，不能把基础换天的执行回执直接当成最终作品验收。
