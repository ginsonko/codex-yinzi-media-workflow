# Live-action adaptation and performance

## Evidence boundary

Recent animation-to-live-action attempts returned real videos but exposed frozen bodies, an unfamiliar face and a motion repair that reframed the shot and introduced an unwanted foreground prop. These are **failure lessons**, not an accepted full cinematic conversion. A later local salvage assembled a 13.33-second concept sample from usable intervals with an editable AE project and separate dialogue/music/ambience/effects; this demonstrates a shorter delivery route, not a successful one-minute remake or repaired acting throughout. Judge each delivered revision on its actual render. The narrower successful replacement route is in [character replacement](character-replacement.md).

## Check the reference assets first

Inspect source video around every selected transition, not just a contact sheet. Build a small identity/continuity sheet for the characters actually present, including supporting cast: face, hair, build, costume, important props and scene geography. Compare generated reference images with the source before using them as identity anchors. An attractive portrait with the wrong face, an implausible face in a room, or an appliance in the wrong color/location is a reference defect; more detailed video prompts will not reliably repair it.

Reuse good assets and keep only references relevant to the shot. Distinguish an identity image from a pose reference and a setting plate. Examine overlays, subtitles and source quality before submission: inherited overlays can be reproduced in generated frames. Use clean authorized source material where available and keep provenance in the project records. Check the actual image/video/audio reference contract; a cheap image-only route cannot silently stand in for video-conditioned reproduction.

## Preserve the right things

Separate identity, action, blocking, camera, setting, props, speech timing and soundtrack. Preserve the user's chosen subset; do not assume freedom to reframe a shot they asked to retain. Natural live action needs motivated breathing, weight shifts, glances and gestures beyond an animation's held pose. Describe performance without inventing new story objects.

If matching animation composition repeatedly freezes the actor, identify that conflict instead of cycling through synonyms for “natural.” When the user permits cinematic adaptation, keep the agreed story, dialogue and approximate timing while letting blocking, shot scale and camera motion support real performance. State those priorities explicitly. This is a changed creative constraint, not proof that strict frame-for-frame conversion works.

Images guide identity/style; avoid forcing every pose back to a still. For continuous scenes derive the next start from the previous **actual accepted output**, checking eyelines, direction, distance and prop ownership. Final-frame or video references are useful only when the current model supports them. Do not invent a video-reference contract for an image-only model.

For a localized defect, test a representative short interval while preserving surrounding accepted footage. Interval/request duration follows the defect and model contract, not a universal four-second rule. Record requested and returned duration separately; extra output duration is not guaranteed or proof of settled price.

Evaluate an actual head/neck/shoulder turn, gaze change or hand-object action before extending a costly sequence. Mouth-only animation, an entire image drifting, and interpolated frames do not establish natural acting. Plan cost against the requested contract; occasional output longer than a four-second request is not a dependable way to obtain a thirty-second scene. A failed or refunded request is not an accepted sample, and a successful short response does not validate the remaining story.

## Diagnose the defect

| Observation | Next useful action |
| --- | --- |
| Mouth moves but body freezes | Ask for motivated continuous acting; check held source animation. Interpolation or a camera pan cannot create missing performance. |
| Motion improves but framing/props change | Remove prompts that introduce objects; preserve prop ownership and any composition the user still requires. If reframing was authorized, judge story clarity and continuity instead. Compare before splicing. |
| Wrong face in a middle shot | Check identity throughout, repair the defective interval with a relevant clearer reference, retain unrelated good shots. |
| References produce a pose montage | Reduce conflicting pose constraints and describe action progression and transition state. |
| Download fails after generation succeeds | Recover that task's asset/download. An explicitly chosen new generation within authorization uses a new attempt while preserving the old task and unknown charge. |

Inspect transitions and fast motion, then watch the entire output at normal speed. Check identity, natural acting, hand-object contact, spatial continuity, audio and story meaning. Decode success is insufficient. Save rejected results and reasons as evidence, not as permanent retry locks.

## Salvage locally when generation stops

Respect the user's stop/budget decision and inventory the existing videos. Record source file, in/out, playback speed, face/prop validity and audio choice for each useful interval. Check for a hidden cut inside a selected range and avoid reusing overlapping source moments unless the user deliberately wants a reprise. Exclude wrong-face or broken-contact shots; do not describe cropping, motion blur or a flash as an identity repair.

Build the shorter edit around a readable event or reveal. A soft focus transition can bridge an atmospheric passage; a hard cut may suit an impact. Use source handles for transitions without repeating the same action in adjacent shots. Preserve meaningful dialogue and ambience, then choose and mix music with [music-driven editing](music-driven-editing.md). Keep the editable project, source interval list and rejected ranges so a later revision can change only the affected section.
