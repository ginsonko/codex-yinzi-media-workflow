# AI漫剧：详细文本指导，按用途选择参考图

适用于从故事生成原创漫剧、动画、打斗或表演片段。精确复刻、指定逐帧姿势、客户已锁定分镜时，遵守该任务要求；已有源视频的角色替换继续参考 [character-replacement.md](character-replacement.md)。

## 文本负责导演，图片提供视觉依据

文本提示词可以详细约束剧情因果、动作顺序、攻防接触、人物表情、台词、时间安排、机位、运镜、场景方位、画风与不能发生的变化。用户要求写细或写死时就明确写出。让模型发挥，是让它依据这些文字实现自然连续的画面，不是让它自行更改剧情或忽略导演指令。

参考图总量按实际需要安排，可以多；重点减少的是严格锁定连续动作瞬间的分镜图片，而不是所有图片。人物、服装、道具、美术风格可有充分的参考，保留几个关键构图或画风分镜即可，不将每个中间瞬间绑定到独立抽卡的图片。不要把这一原则扩大成少写文本、删除时间约束或默认放开中间动作。详细文本仍需内部一致，片长应容得下指定事件；发现文本自相矛盾或动作过载时，针对问题修改并说明，不能无依据降低细致程度。

| 内容 | 初次制作的处理 |
|---|---|
| 剧情、动作、台词、表情、镜头与时间 | 通过详细文本明确指导，按用户要求保留精确约束 |
| 角色面貌、标志服装、重要道具 | 按需要提供清楚、互不冲突的权威图片；数量不限于一两张，文字说明各图约束什么 |
| 多个动作瞬间或连续场景构图 | 详细文字指导连续动作，按需保留几个关键构图；不因已制作分镜图就要求逐一命中全部瞬间 |
| 特定美术设计或已经暴露的一致性问题 | 增加或替换针对该问题的参考图，实际有效就保留 |

## 首轮选图与制作

保留故事、人物、详细文字分镜和视频脚本。是否生成分镜图、预演以及制作多少，取决于它们能否解决实际需要；不把全套分镜图生成完当成视频制作的前置门槛。已有图片仍可用于内部规划、美术沟通和宣传，未上传不等于浪费或删掉成果。

先按用途选择身份、服装、道具、画风、场景和关键构图参考，同一人物也可以有多个互补视角。首轮即可加入有明确价值的美术与关键构图参考，不必等生成失败才补图。对连续动作不按秒铺满强制姿势图；每张参考说明生效范围，避免身份图的站姿被误当动作约束。不设置固定总图数或角色图数量上限，也不是所有镜头都必须用图；仍遵守当前模型合同容量。

检查参考间的脸型、衣服、伤势、武器、光照与空间关系是否冲突，明确每项关键特征采用哪个权威定义。不要把独立抽卡生成、略有差别的姿态图全部绑定成必须逐一命中的瞬间。多格拼图虽然只有一个文件，仍有多个画面；同样需要区分身份/画风说明与连续动作约束，不能仅按文件数量判断约束多少。

每份实际提交的参考按当前渠道逐一引用并说明用途。删图后同步重排引用序号，不能遗留不存在的图片编号。身份图只定义外观，不暗示逐帧复刻其姿势；场景图只规定实际需要的设计。不支持首尾帧时只用普通参考，不承诺像素级锁定。实际分辨率以请求参数为准。

在授权内先生成能检验难点、又可进入成片的短段。先播放完整视频检查动作与声音，再看关键接触帧、表情和细节。静态接触表不能单独证明动作连续。结果合格就直接复用，不额外制作只为证明理论的付费样本。

## 连续场景按实际成片接续

同一场景中相邻片段的站位尚未确定时，不提前批量生成并锁定后续片段的空间构图图。先完成上一段并检查实际成片，再确定下一段的站位、背景距离和构图参考；已有全套分镜图保留为规划资料，与实际成片冲突时更新或停用对应图。身份、服装、道具和画风资产仍可提前准备，互不依赖的独立场景仍可并行制作。

每段通过后，记录实际延续状态：人物和敌我阵列的相对位置、相互距离、面向及视线目标、背景锚点、伤势与道具、运动方向，以及镜头景别和轴线位置。先选上一段中可用的相关视频区间作为下一段的普通参考视频，让模型参考连续动作与空间关系；再按需要制作少量关键构图图。逐个引用参考并说明约束的是身份、动作还是空间。视频参考受当前渠道容量、格式和授权约束；不支持时从合格片段取有代表性的清楚帧并附空间说明，不冒充首尾帧锁定。不要让有明显漂移的上一段继续成为权威参考。

交流镜头必须明确谁对谁说话，人物世界位置、脸朝向、目光落点和屏幕左右关系应共同成立。双人同框、过肩或正反打均可；正反打通常保持180度轴线，换轴先建立可读的过渡。内心独白、刻意回避对视或直接对观众讲话按剧本处理，不机械要求所有台词都两人对视。

跨镜检查分清世界坐标和画面坐标。正常景别或焦距变化可以改变表观大小；没有叙事动机时，不应让人物从远离背景突然贴近背景、阵列越过人物、地球从远处弧面突然变成近处小球。不能只用“角色仍在画面右侧”证明空间连续。简单短转场和声音交叉淡化可改善接缝，但不能修复这种空间矛盾。

## 可选3D空间预演

多人攻防、大尺度背景、换机位或反复出现距离漂移时，可使用现有 Three.js/Blender 导演台建立轻量空间预演，详见 [blender-director-api.md](blender-director-api.md)。固定同一套人物、军阵、背景坐标与比例，设置镜头位置、焦距、目标点和人物朝向；下一镜复用场景，只改变有动机的相机或角色运动。先看两镜是否连续，再从该场景输出构图或参考视频，结合权威美术资产指导生成。

低配机器先用占位几何和低分辨率短预览即可。占位预演只证明空间规划，不是最终角色画质；3D参考也不能保证生成模型严格保持坐标，最终仍需检查成片。不把复杂建模、安装新重型依赖或额外付费样本变成每项漫剧任务的前置步骤。

向生成模型提供3D截图或视频时，明确它只定义空间、机位或动作，人物外观和画风以已认可实片及权威美术资产为准。通用参考可能连占位几何外观也一起模仿；按实际渠道选择空间文字、深度/线稿控制或普通参考，不一律禁用灰模，也不把它当最终美术首帧。若成片出现镜像翻转，先核对持剑手、伤势侧、服装标记、文字和环境锚点；不能仅为修正屏幕左右就翻转整段。

## 依据实际问题增补图片

对于空间已经正确、但景别或姿态在接缝处轻微跳变的片段，先试有动机的短叠化或短暂失焦过渡，并同步交叉淡化原声。过渡只占接缝附近，之后恢复清晰；检查双脸、重影、突黑、台词截断及总时长变化。它能柔化剪辑观感，不能补出真实中间动作或修复世界坐标错误。识别对白时若ASR结果与脚本不同，回读原声再判断，不把识别文本直接当成模型实际说错的话。


| 实际问题 | 优先处理 |
|---|---|
| 摆姿势式停顿或动作衔接不自然 | 检查是否有冲突姿态图，减少或替换这些图片，保留清楚的动作文本；另查事件密度和文字矛盾 |
| 角色、服装或道具漂移 | 确认现有权威图清晰且与文字一致；必要时增加针对该特征的图片，而非追加整套分镜 |
| 构图或攻防空间不清 | 先把文字关系写准确；若仍失败，再补一张对应构图参考 |
| 跨镜光照、伤势或面貌不一致 | 检查剪辑切点，必要时从上一段合格实片取清楚帧，替换冲突图；不传播已经变形的帧 |
| 表情、台词或节奏不符合剧本 | 定向完善文字表演要求、时间与剪辑；不默认认为每类问题都需要更多图片 |

允许增加、替换、减少参考，不设只增不减的固定阶梯。已合格片段保留；重做只处理受影响片段，在原授权与预算内执行。保存每次实际使用的图、详细提示词、原片、请求身份和质量结论。未知结果可查询原任务；已有授权与预算内也可明确重试，归档旧尝试并使用新请求身份，不要求额外确认或先证明未扣费。下载故障优先恢复原文件。

## 经验与证据

详细文本与按用途选择参考图是可按任务调整的制作策略。总图数不是质量指标，减少逐瞬间硬分镜与保留充分身份/美术参考可以同时成立。多张独立生成图可能引入互相矛盾的视觉要求；不等于“多参考一定更差”或“少图一定改善”。没有受控对比时，不能把某次道具变化或动作停顿直接归因于参考数量。
