# 商品视频研究 · 用户试用版

这次更新把「找同类视频 → 看实际数据 → 选参考 → 观片与原创策划 → 媒体制作」接进同一个工作流。适合需要商品视频参考、带货脚本或广告创意的用户。

## 更新后怎么用

把下面这段话交给 Codex 或已经接入工作流的 Agent：

```text
请更新银子万能媒体工作流，保留已有配置、任务和平台登录资料，执行安装器激活新版 Skills/MCP 并返回工作台地址。
然后帮我找「我的商品」在「目标平台」上的热门参考视频，给我看有出处的数据报告，实际分析重点样本，结合我的商品资料做原创脚本、分镜和制作方案。
```

直接使用页面也可以：打开工作台的 **商品视频研究**，输入商品与平台，点击「开始找参考」。平台需要账号时，点击连接区按钮，在独立的官方浏览器窗口扫码或完成验证，再点击「我已完成验证」。不用复制 Cookie 或 Token；当前研究会接着采集。

报告支持筛选、来源核查、同平台指标比较、参考选择以及离线 ZIP 下载。选择参考、填写自己的商品事实后，点「进入视频策划」或「复制给 Codex」。Agent 会继续观片、设计原创脚本、分镜和制作；用户可以持续提要求、修改局部。

## 这次接通的内容

- 抖音、小红书、B站、TikTok、YouTube 专用入口及其他平台通用研究入口。公开检索、视频详情和用户授权登录后的读取共用规范化数据。
- 研究进度、每次采集与报告版本保存在本机。中断后恢复同一研究；部分平台失败仍可使用已有报告。停止后保留当前已取得的结果。
- 只为真实数据画图。未知指标不填零，搜索摘要不混作原站热度，不把不同平台直接合成一个排名。
- 能查看和选择全部采集记录；观片分析注明实际范围。商品事实、重点参考及可修改拍摄框架随版本一起交接。
- 新增 `product_video_research`、`research_platform_connection` 两个 MCP 入口，以及等价 `research` / `research-platform` CLI。主媒体 Skill 已加入相应触发条件和流程，用户无需记工具名。

## 实测范围

Windows 上已完成抖音官方验证后的同页接续，取得26条新原站视频记录，包含实际点赞、评论、收藏与分享；未返回的播放量保留未知。报告、参考选择、部分观片记录和原创策划资料已进入制作工作台。B站公开详情另有真实采样验证。

小红书与 TikTok 已覆盖解析及失败恢复测试，本轮没有实时成功采集证明；YouTube 在测试网络出现超时。跨系统路径已经实现，macOS/Linux 的官方登录尚未实机验收。平台改版、地区网络、登录与限流会影响可取得的数据，并非全平台全量数据库。

本次研究不调用付费图片、视频或文本生成 API，宿主 Agent 的使用仍按其服务计费。后续制作沿用户已有模型配置与预算。公开互动数据帮助选择和验证创意方向，不能证明销量或承诺爆款；客户真实商品成片和投放效果需要各自验收。

研究不会自动发布视频。更新保留本机数据；GitHub 源码不含客户研究文件或登录资料。
