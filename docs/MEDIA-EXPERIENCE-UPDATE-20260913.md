# 制作经验、工具选择与本地合成更新

这次更新让常见角色替换先走更快的路径，并让本地处理留下可复用经验。
正常更新仍使用原有安装器，保留任务数据库、素材与已安装组件。

- **角色替换先看简单路径**：支持参考视频的 Seedance 2.5，可先使用一张清晰角色图、源视频和短提示词。故事板、反推、分段与本地逐帧处理保留为针对具体质量问题的升级方案。实际时长和画面仍需检查。
- **上传更兼容**：上传使用安全文件名，并识别常见媒体的真实格式；图片扩展名和内容不一致时校正传输 MIME。原始文件保留，已取得的文件 ID 继续复用。
- **制作经验**：工具目录增加“制作经验”。本地任务自动记录执行结果、组件与参数摘要；用户与 AI 可补充做法、适用条件和内容质量。纠错保留历史，重启可以补回尚未写入的经验，不重复执行媒体任务。记录保存在本机任务数据库。
- **本地节奏与合成**：新增音频瞬态分析、多图层与蒙版合成、多素材剪辑合成。缺少已注册组件时沿同一任务自动准备；完成后保留来源校验、实际成果与执行记录。
- **探索制作方案**：工具目录提供 129 条可检索的研究选项，涵盖 MAD、MV、高光剪辑、鬼畜、蒙版和帧处理等。每项列出工具、备用路线、依赖和设备估计；其中 13 项可复用已有基础操作。待接入方案明确标识，不能直接当作新执行器数量。
- **恢复与文件预检**：本地路径、远程引用及提供方文件 ID 分别处理；远程引用不会被误当成本机文件。多素材请求保留各来源身份，恢复和经验写入保持同一任务关联。

本机验证包括：206 个本地媒体操作的真实小样执行；两份用户视频、五个片段的真实接口合成；电商原图的蒙版排版合成；组件自动下载后续作；经验写故障后的重启恢复；移动端 390px 搜索与详情。小样证明相应执行链路，不代表所有题材、设备或视觉效果已验收。Windows 为当前本机验证平台。

本轮没有新增收费视频请求。文件名兼容改进不代表已证明某笔供应商失败的根因；一般错误保留原请求进行查询。模型参数以所选站点的当前合同为准，不把其他版本的时长限制照搬过来。

本次更新不包含已验收的全自动高质量 MAD/MV 引擎、全部重型组件安装器或 500–1000 个可执行工具。这些继续作为后续独立的实现与实测工作。
