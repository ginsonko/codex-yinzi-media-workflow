# 图层关键帧

`local.video.composite-layers` 可以把图片、视频、蒙版与底片合成。每个图层可配置独立的 `x`、`y`、`scale_x`、`scale_y`、`rotation`、`opacity` 时间轨道，使用已有 FFmpeg 组件在本机完成，不需要视频生成模型。

## 何时使用

- MAD、MV 或商品广告：先用节拍分析得到切点，再把文字/产品/装饰图层的关键帧放到切点附近。
- 教程标注：用 x/y 轨道跟随已分析的目标位置，用 opacity 控制强调的出现和消失。
- 逐帧编辑：以 `time = frame_index / fps` 设置关键帧。先做好抠像/蒙版，再做运动合成。
- 只需整幅画面推拉平移时，`local.video.camera-motion` 更直接；需要图层各自变化时用本操作。

这是 FFmpeg 本地合成器。AE 工程控制需要单独的 AE 适配器及实际软件环境。

## 时间与坐标

关键帧 `time` 单位为秒，从该图层的 `start` 开始计时，不是源视频的时间戳。`source_in` 只决定从素材哪里开始取片。x/y 是合成画布内未变换图层的左上角像素坐标；缩放和旋转围绕图层中心。旋转单位为度，正数顺时针。

`value` 是属性绝对值。有轨道时取轨道值，无轨道时保留静态属性。opacity 在 0 到 1 之间，仍与原素材 Alpha、蒙版相乘；不会使原本透明的像素变得不透明。scale_x/scale_y 是独立倍率，允许非等比缩放。

首个关键帧之前保持首值，末个之后保持末值。关键帧时间严格递增，并在图层的请求区间内。`easing` 控制从此关键帧到下一帧的过程：`linear`、`hold`、`ease-in`、`ease-out`、`ease-in-out`。hold 在下一关键帧时刻立即切换。图层 end 不包含在显示区间内；素材或蒙版提前结束时停止显示，保留实际结束点。

## 参数示例

在现有 `local_media_run` / CLI 本地作业中使用以下参数。sources[0] 是底片视频，sources[1] 是产品图或视频，sources[2] 是可选蒙版；三个源均保留不改写。

```json
{
  "module_id": "local.video.composite-layers",
  "parameters": {
    "fps": 24,
    "audio_mode": "source",
    "layers": [{
      "source": 1,
      "start": 0.5,
      "end": 2.5,
      "width": 320,
      "height": 240,
      "x": 160,
      "y": 100,
      "animation": {
        "x": [{"time": 0, "value": -320, "easing": "ease-out"}, {"time": 0.5, "value": 160}],
        "scale_x": [{"time": 0, "value": 0.6}, {"time": 0.5, "value": 1}],
        "scale_y": [{"time": 0, "value": 0.6}, {"time": 0.5, "value": 1}],
        "rotation": [{"time": 0, "value": -12}, {"time": 0.5, "value": 0}],
        "opacity": [{"time": 0, "value": 0}, {"time": 0.25, "value": 1, "easing": "hold"}, {"time": 1.75, "value": 1}, {"time": 2, "value": 0}]
      }
    }]
  }
}
```

## 实施顺序与经验

1. 先确认底片尺寸/时长/音轨，以及图层素材与蒙版的对应关系。不同原始时间戳由合成器归一化。
2. 先定图层起止与目标尺寸，再填属性轨道。主音轨从底片保留，图层音轨不自动混入。
3. 蒙版先作用在图层自身坐标内，然后与图层一起变换。避免先移动画面后仍用原坐标蒙版造成错位。
4. 检查开始、关键帧边界、结束和运动中点。缩放/旋转需要透明扩展画布；过大的工作画幅应先缩小素材或拆段。
5. 复杂动作先跑短预览；确认构图、节奏、边缘与音轨后再运行全片。单个操作技术检查不代替最终作品观感。

参数 schema 与执行器共用同一轨道定义；非法数值、未知属性、重复时间在编码前返回 `KEYFRAME_TRACK_INVALID`。轨道只接受结构化数字，不接受脚本或 FFmpeg 表达式。当前每属性最多 100 个关键帧，作业参数 JSON 总量仍受既有 16000 字节限制；六条轨道同时填满可能超过总量。长逐帧序列应按片段分批合成。
