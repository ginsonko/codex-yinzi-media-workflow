# v0.2.0：画布创作助手与银盐工作台

本版将持久化创作画布、专用助手、异步媒体交付和新的「银盐」界面配套发布。既有手动批量多模态生成、热门与商品视频研究、本地视频、制作向导、导演台和 Skills/MCP 入口继续保留。

## 画布既能手动用，也能交给助手

在「画布创作」创建项目，添加剧本、图片、视频、音频节点，上传已有素材，拖动连线指定普通参考、首帧、尾帧或上下文关系。每个节点可以独立选择模型及参数；已有结果可以再次生成并保留历史版本。

右侧助手可以独立设置 Base URL、Key 与文本模型。它与手动操作共享同一份画布：读取、编辑、连接参考、生成、分析与导出都有实际工具回执。支持 OpenAI Chat Completions 的工具调用，以及明确选择的 JSON 动作兼容模式；不同模型的工具调用能力仍取决于其实际支持情况。

外部 Agent 通过 `creation_canvas` MCP 工具及配套 Skill 配置和引导画布助手、观察执行、纠正和验收；用户也可以直接在工作台完成操作。

## 生成结束，结果自动回到画布

上游查询、下载、任务状态和助手对话现在共享交付进度。助手结束一轮文字回复后，后台仍继续跟踪异步生成；结果到达后自动下载、更新节点，并留下含本地链接的完成通知。

- 明确区分生成中、已生成待下载、下载中、下载失败待恢复与本地已完成。
- 普通整文件下载遇到传输失败时，支持同一产物的分段下载回退和完整性验证。
- 历史下载失败批次恢复后能正常收尾；下载恢复沿用原任务，不自动发起新的生成。
- 新旧尝试分别记录，旧任务迟到的结果不会覆盖当前选择；完成通知按尝试去重。
- 助手读取画布时能看到实际本地交付状态，避免把“上游已成功”与“本地可播放”混为一谈。

## 新界面与原有能力配套

首页、任务、配置、批量、素材库、剧集、导演台、画布和工具目录统一采用银盐设计。界面提供完整、均衡、轻量、极简四档效果，方便按机器性能选择。工具目录默认展示全部 312 个能力模块，也保留分屏选项；模块数量不代表每个可选组件已经安装或每个云服务已经配置。

逐项批量生成继续支持各自的提示词、模型、图片/视频/音频参考；image2/image2.5 的比例、1K/2K/4K 和 21 种尺寸映射仍在。费用预估和预算提醒只提供参考，价格缺失或超出提醒值不会禁用显式生成、重试或重新生成。

## 更新和启动

已有源码安装在原仓库目录执行：

```bash
git pull --ff-only
```

随后运行当前系统安装器：Windows 使用 `install.cmd` 或 `install.ps1`；macOS/Linux 使用 `./install.sh`。安装器更新依赖、构建前端、同步 Skills/MCP 并启动对应运行时，保留本机配置、Key、任务和素材。仅拉取源码不会让正在运行的旧后台自动变成新版本。若自己修改过源码，先合并本地改动；不要通过删除数据库或重置工作区解决冲突。

没有新生成需求时，更新和验证不需要调用付费模型。新用户按仓库 README 的安装步骤即可。
