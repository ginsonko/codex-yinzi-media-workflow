# 2026-09-14：多宿主接入与本地媒体能力更新

本次更新增加 Grok 的 MCP / Skills 安装入口，并发布已集成的本地媒体能力与任务恢复修复。Grok 用户可以在插件目录运行 `node scripts/install-host.mjs --host grok`；桌面版独立 Agent 目录的配置方式见 [多宿主安装](MULTI-HOST.md)。

## 可以使用的增量

- 多宿主配置支持 JSON、JSONC、TOML，保留原配置与注释，提供备份、回滚和自定义位置。Grok 自动同时安装 Skills；支持独立 `GROK_HOME`。
- AE 工程桥接与专业制作指南，通用图层关键帧、逐帧导出与回组；按真实安装情况使用本地后期软件。
- 天空分割与图片/视频换天、前景分割、人脸区域处理、镜头分析、素材下载索引、系统配音与本地语音识别等已注册执行入口。具体组件、平台和效果边界以工具目录与各功能文档为准。
- 模型中立镜头结构和提示词适配，保留参考绑定、时长和渠道合同差异。
- 明确拒绝后的重试进入新尝试，保留历史；未知或已受理的生成继续查询原请求。修复本地处理已成功而界面仍显示旧失败的问题。
- Skills 按宿主真实任务身份保存媒体任务，区分新目标与续做；明确的批量请求可直接进入持久批次。进度回执默认精简，完整内容按需读取。
