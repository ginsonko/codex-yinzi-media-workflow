# 教学视频、拍题讲解与交互演示

把不会的题目照片或想讲的知识点交给 Agent，可以一起制作讲解视频、解答长图和适合内容的交互页面。学生用于答疑和复习，老师可以制作课堂演示、网课资料与教案。展示形式根据学习目标选择，不要求每道题都做齐全部格式。

## 看实际作品

- [四种教学示例](https://workflow.yinziapi.top/learn/)：物理运动、数学坐标、诗词赏析与截图题。
- [截图题完整讲解与实验](https://workflow.yinziapi.top/learn/table/)：两问推导、八个章节、完整变式、解答长图，以及入口和半径可调的第一次出界演示。

```text
请把这道题讲明白。先识别题目条件并独立核验，再按我的基础设计讲解，制作视频和便于复习的步骤配图。适合动手理解的部分，请做可交互演示，让我调参数验证；最后用一道完整变式检查我是否学会。保留可修改工程。
```

## 安装与调用

`yinzi-educational-video` 与主工作流 Skill 位于同一个插件的 `skills/` 目录。现有安装器按目录发现并复制全部 Skills，无需用户另外复制文件。主工作流遇到教学需求也会引导读取此技能，并复用当前任务、资产和进度。

技能包含音频测时、公式渲染和媒体检查脚本。FFmpeg、Manim、TeX 或所选语音工具按实际任务准备；没有相关依赖时不应宣称已经渲染成功。在线语音、云端图像和视频按各自服务计费，本地精确轨迹与几何无需视频生成模型。

## 本轮留下的方法

- 先识别条件、独立求解，再写讲稿；截图中的答案不能替代验证。
- 轨迹、向量、公式和数值使用同一个参数模型；科学运动不能由生成视频代替。
- 按真实口播长度安排画面，留出阅读公式的时间。
- 交互展示第一次越界和临界点，并测试边界两侧及变式；完整圆上的后续交点不是实际首次出界。
- 适合探索的关系主动做交互，讲解与复习分别用视频和长图，按学生需求调整。
- 实际导出后完整解码、抽帧检查、测量音频；技术检查不等于学科或主观听审。

这些方法来自 Windows 上的实际教学案例。它们不保证任意截图、学科或生成结果都正确，也不等于完成了所有系统和宿主的实机验证。诗词中的 AI 画面为意境演绎，不作历史影像证据。
