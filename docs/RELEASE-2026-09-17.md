# 20 位作品监督、入门引导与制作经验

这次更新让任务可以保留自己的审美方向。工作台新增「作品监督」：内置 20 种创作视角，包括小高级、小乐子、小燃、小导等，支持查看、编辑、复制、停用、删除、恢复内置版本和 JSON 导入导出。

每次任务给出主推荐和两个备选，可手选、自动选择或关闭。选择会保存成任务快照，进入 Agent 的创作上下文；修改目录不会悄悄改变进行中的作品。方案、粗剪和成片意见可带时间码、实际证据与版本记录，后续继续任务时仍可读取。监督使用现有 Agent，不会自动调用 20 个外部模型；自评与独立审片分别记录。

模型与 Key 页补充银子 API 首页和 Codex 配置教程入口，同时保留其它服务商配置。新用户仍可先不配 Key 看示例，安装不会发起模型生成。

随 Skills 分发的经验更新了 MAD 和原声鬼畜的实际反馈、宣传片的信息层次与连续音乐、同源前后对照、AE 渲染参数与恢复细节。全新安装也能读到这些公开指南；本机项目笔记保留用户自己的结果与后续修正。这不会训练或改变模型权重。

## 验证范围

监督管理、真实 HTTP、SQLite 恢复、MCP、CLI 与桌面/移动浏览器均有测试。独立审查发现并修复了大目录无法导回和延迟保存关闭新草稿的问题；复核覆盖 3101 项完整交换、4 MiB UTF-8 精确边界和请求延迟反例。

单个监督交换包上限为 4 MiB，较大目录可显式分批导出，导入始终创建新副本。跨批次同时编辑不构成事务一致的整库备份。三平台安装入口和可配置宿主适配继续保留，具体本地组件与宿主实测范围见对应文档。

升级保留现有数据库、Key 和任务记录。先使用原安装位置的更新/安装入口，读取实际工作台地址；不要为升级创建另一个空数据库。作品监督的使用与能力边界见 [说明](STYLE-SUPERVISORS.md)。本次不改变个人非商业免费与商用另行授权的许可证。
