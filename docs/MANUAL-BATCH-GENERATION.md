# 在工作台中直接生成图片和视频

打开工作台左侧 **批量生成**，选择 **逐项编辑 · 上传参考**。不需要打开 Codex 或编写脚本；只需先在 **模型与 Key** 保存要使用的模型服务。

## 生成一条，或同时准备多条

1. 选择图片或视频，填写任务 1 的提示词。
2. 为这一条添加参考图片；视频任务还可分别添加参考视频和参考音频。上传成功后可预览、调整同类素材顺序或移除。
3. 选择本项模型，或使用页面下方的默认模型。每个任务可单独覆盖画幅、图片尺寸档位、视频时长和分辨率。image2 / image2.5 按 1K、2K、4K 与画幅联动显示并提交具体像素尺寸，其它图片模型可填写自定义尺寸。视频任务中的参考图片可指定普通参考、首帧或尾帧，具体用法以所选模型为准。
4. 点击 **生成这一条**。需要多条时点击 **添加一条任务**，逐项填写不同的提示词和素材，再统一生成。复制任务会复制设置和已上传素材，后续编辑不会修改原任务。

模型能力提示优先读取当前配置的有效能力，包括三类参考素材数量、总数、时长、分辨率和图片用途。目录未知或暂时离线时仍可填写模型名和参考素材；系统不会因此换模型或删除附件。模型确实不支持的输入会按供应商原始结果显示，请据此调整。

完整图片／视频／音频参考链路目前通过 Yinzi 视频协议对接。其它协议的手动视频／音频参考尚未对接时，页面会明确提示；切换模型保留附件，但不把未支持的适配器描述成完整多模态。目录未标注严格首尾帧支持时，现有适配器会使用普通参考并补充开场／收尾提示，不保证精准锁帧。

需要编号引用的模型，可在提示词中使用其约定的 @图片1、@视频1、@音频1。编号分别按照各类参考素材的当前顺序；调整顺序后检查提示词中的对应关系。首尾帧分别只指定一张，其余图片使用普通参考。

## 草稿、进度与重试

- 草稿保存在当前浏览器；图片与视频分别保存。切换编辑模式、刷新或重新打开页面后，已成功上传的素材和逐项设置仍在。
- 上传失败的文件可直接重试。刷新打断的上传需要重新选择文件；未上传完成的素材会明确显示，生成按钮等待附件完整，避免静默丢图后收费。
- 开始生成后，任务由本地后台队列管理，关闭当前页面不会取消已提交任务。队列显示每项模型、素材数量、进度、错误和成片，可播放或打开结果。
- 未收到提交回执时，可选 **恢复上次提交（保留原素材和参数）**，按保存的原请求身份恢复；也可选择 **直接新建一次**。原记录继续保留。
- 已成功、失败或结果未知的任务都可以 **重新尝试**；这是一次新的生成尝试，可能再次收费。恢复同一提交或下载与重新生成不同，不会伪装为同一动作。
- 原来的 **快速逐行批量** 保留：适合不需要独立素材的纯文字大批量任务；逐项草稿不会被切换操作清空。

上传素材保存在工作流配置的本地素材目录，草稿只保存这些持久地址和文件信息，不在浏览器保存文件二进制。实际上传格式/大小和模型输入能力以上传接口及供应商为准。

## 更新与验证范围

在原安装目录拉取默认分支后，运行对应系统的安装器以构建并激活前端更新。只拉源码不会替换已经运行的旧前端；保留数据库、模型配置和已有任务。

本次验收使用隔离 SQLite、真实 multipart 上传、实际视频提交/转换/下载代码和本地模拟供应商，覆盖逐项三类素材、不同模型配置、首尾帧、刷新恢复、上传失败重试、成功后再生成与旧快速批量。桌面和 390px 页面完成浏览器操作检查。未调用真实收费视频模型；这些结果证明交互和请求链路，不代表所有供应商或模型的生成质量。
