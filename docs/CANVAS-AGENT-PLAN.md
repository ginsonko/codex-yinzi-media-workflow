## 最终体验
工作台有独立的「画布创作」入口，画布节点可承载剧本、角色/场景图片、视频、音频和参考关系。用户直接上传素材、拖动连线、编辑参数和生成；右侧专用 Agent 使用独立选择的 URL/Key/模型，读取同一画布并通过工具修改、调用现有生成与分析、观察结果。宿主 Codex/MCP 可配置、发消息、观察、暂停/纠正与验收，同样落到这一份后端数据。关闭或刷新页面不丢任务，也不自动重复收费。

## 实现顺序
1. 读取参考实现与现有合同，完成一次计划对抗审查。建立画布、节点、边、消息、运行/工具结果的持久化与恢复；版本冲突保留用户修改。
2. 接通统一画布操作：增改节点、连线、引用解析、上传/素材库导入、生成快照、结果回收、研究资料导入、现有分析及成片导出。用户显式再生成创建新尝试；网络恢复使用请求身份避免重复。
3. 专用Agent：独立引用text配置，支持用户URL/Key/模型保存，正常tool calling及结构化动作兼容；后台执行、事件/工具记录、取消/纠正和重启后明确中断；不伪造等待或成功。
4. 前端可用界面：画布列表/新建、平移缩放/节点编辑/连接/上传/结果与任务状态、Agent配置与对话、手动执行/观察/干预。样式沿现有主题，保留后续视觉优化空间。
5. MCP与Skill接入相同API，让外部Agent管理、引导与读取执行结果，不需要重复鼠标操作。说明能力、输入与误用恢复。
6. 隔离测试：工具模型HTTP模拟 -> Agent多轮操作 -> 上传/参考关系 -> 现有生成队列 -> 本地模拟供应商 -> 真实结果落盘 -> 浏览器显示/导出。覆盖手动与Agent同时编辑、断网/空响应/取消/刷新/重启、串图与重复生成。真实供应商质量与全平台未知单列，不冒充生产验收。
7. 跑相关回归，核对手动创作、研究和已有主路由保留。交付准确基线目录、启动方式、可用链接、测试证据、前端交接说明和剩余事项。

## 对抗检查重点
- 不能把聊天文本当成功动作；工具返回真实节点/任务/文件身份，日志可查。生成运行与Agent轮次分别记录。
- 生成前按当前引用取已完成产物并固化快照；未完成依赖明确等待，不丢附件。上游完成后可接续，不自动重复已有attempt。
- 不把旧全图快照覆盖用户编辑；操作按实体、版本和当前值应用。选中节点及请求的画布ID固定，切换界面不能串会话。
- Key只在现有配置位置；不进入节点/消息/日志/导出。提示词、研究文字是资料，不扩大工具权限。原记录及明确失败/未知都保留。
- 取消停止后续工具/排队生成，已提交上游请求保留查询身份；人工干预在下一工具边界生效。页面关闭不丢后台运行。
- 不改变原数据库语义和原页面入口；用新增表/模块及受支持现有服务，不覆盖生产安装、历史素材或其它脏工作树。
