# 剪映：可选的本地剪辑路线

把素材和用途交给 Agent，也可以直接说：“用我电脑上的剪映，做一段可继续编辑的短视频，先给我看小样。”工作流会检查环境、准备工程，显示工程名、所在目录和下一步。无需自己编写草稿 JSON。

## 已接入的工具

- `local.jianying.inspect`：检查剪映安装、隔离草稿依赖和当前草稿目录；按需查询滤镜、转场、文字动画等资源名。
- `local.jianying.draft`：准备独立可编辑时间线，支持素材剪辑、文字、SRT字幕、线性关键帧、滤镜和转场引用；可复制可读的本地模板并替换文字、素材。

这两项通过现有 `local_media_run` 调用，按唯一操作ID计入能力目录。资源名不是额外工具；商店模板、会员和模型服务不会因此自动付费。

## 尽量让 Agent 完成准备

选择剪映路线后，Agent 按需准备隔离的 `pyJianYingDraft 0.3.0` 环境，并保留当前用户配置。依赖需要 Python 3.10+；工作流主安装不捆绑安装剪映，也不要求所有用户预装这项可选依赖。

默认自动读取剪映当前草稿保存位置，放入独立副本；无需手工搬 JSON。可以用 `prepare_editor: false` 只生成工程。自定义或其它平台目录可以通过安装脚本 `--drafts-root` 配置，Agent 应代为处理。

工程名称与目录立即显示在任务进度里，可以复制。**从剪映首页草稿列表打开工程**；编辑页“素材→导入”用于媒体，不能打开草稿 JSON。可靠的桌面控制工具可继续帮助预览和导出；如果当前机器无法可靠控制界面，给出最少的手动步骤。

自动准备到草稿位置，不等于已在首页收录、打开、应用全部资源或导出。工程制作和成片交付分开记录；有MP4后还会检查画面、声音、字幕与转场。

## 适合哪些工作

常规短视频包装、可编辑字幕、成熟转场和本地模板变体，可以选择剪映。复杂歌词与人物交互、精密抠像、多层3D关系、独特节奏设计可继续交给 AE；简单批量裁切或转码可用 FFmpeg。工具选择服从作品要求。

滤镜和文字动画资源受软件版本、缓存、账号权益影响。工具能引用的名称，必须在实际导出中确认；本地可读模板的复制不代表在线模板商店已实现自动套用。

## 本机实测与限制

Windows 10、剪映专业版 11.5.0.14471、pyJianYingDraft 0.3.0：12秒720p30预设测试工程已由用户手动打开并导出，360帧完整解码。实片可见标题入场、双语字幕与三处叠化。冷蓝滤镜没有同一剪映工程无滤镜对照，未单独确认。

新接续工具另通过了自动读取自定义D盘目录、真实工程副本准备、重复复用、旧草稿哈希不变测试。这个新副本尚未单独完成GUI导出。当前自动桌面控制存在捕获/坐标接口问题，**不承诺无人值守导出**。其它系统与剪映版本要在任务开始时检查，不能从这台机器外推。

发布前的故障回归还覆盖了三类恢复边界：回执落盘失败不会先产生编辑器副本并在重试时重复建工程；已有副本缺少关键文件时会明确回退到人工检查，不会提示“可打开”；把本工具生成的副本作为明文模板时会重建运行标记，不会因为旧标记冲突而永久失败。编辑器目录中的用户文件仍不会被覆盖。

## 修改与恢复

生成时保留独立原件和回执；剪映使用另一份副本。重试不会覆盖用户在剪映里保存的编辑。新版剪映保存后的文件可能不再是明文JSON，不应解密、覆盖或强制降级；继续编辑器中的工程，或从生成原件另建变体。

找不到草稿位置或副本准备失败时，已经生成的工程会保留，并报告实际目录与原因。Agent 可以修正配置后继续接续。原始媒体可能通过绝对路径引用，跨电脑迁移时需要收集并重新链接素材。
