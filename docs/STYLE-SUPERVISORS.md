# 让作品有自己的审美方向

工作台的「作品监督」内置 20 种创作视角。它们影响 Agent 的方案、镜头、节奏、声音和审片意见，你仍然可以随时修改方向或关闭监督。使用现有 Agent 即可，不会因为启用监督自动调用 20 个模型或产生额外模型费用。

| 监督 | 擅长方向 | 监督 | 擅长方向 |
| --- | --- | --- | --- |
| 小高级 | 精致排版、克制动效、品牌质感 | 小乐子 | 热梗、鬼畜、原声反转 |
| 小忧郁 | 角色向、像素、情绪与氛围 | 小燃 | 战斗、高光、蓄力与爆点 |
| 小导 | 影视叙事、空间、连续性 | 小网红 | Vlog、教程、亲民表达 |
| 小思想 | 主题、现实映射、结尾余味 | 小纪录 | 纪实、访谈、现场与证据 |
| 小潮流 | 社媒视觉、图形字体 | 小诗人 | 意象、隐喻、艺术 MV |
| 小喜剧 | 误导、停顿、反应与回收 | 小悬疑 | 信息控制、伏笔与揭示 |
| 小动作 | 动作、速度、冲击与空间 | 小科幻 | 世界规则、尺度、未来感 |
| 小复古 | 时代材质、像素与采样 | 小治愈 | 生活细节、呼吸与温暖 |
| 小未来社媒 | 竖屏、矩阵、多版本 | 小实验 | 形式探索、生成视觉 |
| 小品牌 | 产品利益、记忆点、广告 | 小审片 | 证据、时间码、具体修复 |

## 开始使用

把创作需求交给 Agent。任务页会给出主推荐和两个备选；推荐会说明风格、适用理由和可能的取舍。普通模式在确定创作方向时选择，挂机/自动模式直接采用。也可以说「这次用小乐子，原声反转再夸张一些」或「关闭风格监督，按我的分镜来」。

每个任务保存独立的人格版本。你在目录里改了小乐子的规则，正在制作的旧片不会无声换风格。在任务页重新采用时才使用目录的新版本，旧选择和审片记录继续保留。

## 修改与分享

- 目录可以新增、修改、停用、删除或复制监督；内置版本可恢复。
- 名称、风格、适用作品、观众感受、取舍、推荐关键词、视觉/声音规则和审片重点都能编辑。
- 导出 JSON 可以分享给别人。导入始终创建新副本，不覆盖同名监督。包中只有文字和规则，不运行脚本或自动下载资源。
- 目录总数不设限制。单个交换包上限为 4 MiB UTF-8 JSON，导入和导出采用同一标准；较大目录可选择当前搜索范围或明确起始序号/数量分批导出，不会悄悄遗漏条目。
- Agent 可通过 `style_supervisors` 与 `task_supervisor` MCP 工具完成相同操作。未即时重载 MCP 时，使用 Skill 中的 CLI。

## 审片如何生效

Agent 在规划、粗剪和成片阶段读取任务快照，将规则落实为具体镜头或声音调整，并记录实际作品、时间码、问题与改法。尚未看到/听到的部分标为未审；有重大问题时先修改。你可以在任务页查看本次审片重点、意见、证据引用及历史。

这是一套可配置的创作和记录协议。作者扮演监督的意见是自评；只有真正调用了独立审片人并取得结果，才有独立审片。监督不会替代技术检查，也不会自动证明作品达到某种艺术水准。
