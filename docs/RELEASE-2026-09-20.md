# 2026-09-20 · 本地歌曲创作与直接重试

新增 `local.audio.neural-song` 和 `yinzi-music-creation` Skill。用户给出心情、故事或歌词后，Agent 先检查电脑，再按需准备 WanGP / YuE2 独立环境，制作真正带歌声和伴奏的短样。支持曲风、歌词、种子、时长、低显存参数及可选 ABC 谱；既有配乐、声音克隆和 PPT 工具保留。

## 更新和开始

在现有安装目录更新官方 main，随后运行当前系统安装器：Windows 为 `install.ps1`，macOS/Linux 为 `install.sh`。不要另建空数据库。运行中任务先保留，空闲时激活新版。安装器同步 Skills 和 MCP；旧会话可先读安装后的 Skill/CLI，新会话会发现歌曲 Skill。

可以直接对 Agent 说：

> 请更新银子万能媒体工作流，保留我的配置、素材和历史；先检查电脑是否适合本地 YuE2，再帮我根据故事写歌词，做一段带歌声的音乐小样。仓库：https://github.com/ginsonko/codex-yinzi-media-workflow

[YuE2 安装与使用说明](LOCAL-SONG-YUE2.md) 包含只读配置检查、独立安装及复用既有模型的方法。首次需要下载环境和权重；更新源码不会无条件下载大模型。Windows/NVIDIA 有真实运行验证，Linux 安装实现尚未实机验收。约 4.5 GB 为低显存路线参考，当前实测使用 8 GB RTX 2070 SUPER；模型权重 CC-BY-NC-4.0，商业项目需选许可合适的模型。

## 重试行为

- 图片、视频的编排、批量与制作流程都允许明确新尝试，失败、结果未知或旧任务处理中不再永久锁死。已有授权内无需再次声称“上游没有任务”或填写强制标志。
- 同一重试命令重复送达保持幂等；新命令可继续重试。旧记录和未确认费用保留，迟到回执不能覆盖新尝试。
- 查询不自动创建付费任务；下载失败优先恢复原下载。预算与暂停仍按用户设置执行。

## 经验和目录

分发歌曲人声控制、真人漫改自然表演、角色身份与动作约束、MV 故事/卡点/连续动作、动态抠像和原生 AE 歌词合成经验。区分实际通过的小样、用户偏好和未通过的全片；不把反复失败的路线包装成成功案例。

源码注册目录为 **301 项模块 / 252 项本地操作 / 49 项其它模块 / 12 个组件包**。58 个转场预设与 20 种监督不重复计入工具数。官网目录可用 `node scripts/export-site-catalog.cjs --output <site>/data --base <site>/data/capabilities.json` 从发布提交重新导出。

## 验证边界

正式本地执行器新生成约 18 秒、48 kHz 双声道 WAV，用时约 279 秒，CUDA 峰值保留量约 3.26 GiB；恢复原结果没有重新推理。该短样证明工具接入，歌词和艺术效果仍需听审，不能据此保证每次整曲逐字唱准。
